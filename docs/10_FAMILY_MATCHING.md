# Revit Family Matching

## Family Catalog

Revit Add-in으로 프로젝트/템플릿의 Family와 Type을 스캔합니다.

수집:

- Category
- Family
- Type
- Host
- Width
- Height
- Thickness
- Material
- Parameters

## Matching Score 예

- Category: 40
- Size: 25
- Type Mark: 15
- Name: 10
- Material: 5
- Company Rule: 5

## Manual Override

자동 추천 후 사용자가 변경할 수 있습니다.

수정된 Mapping은 Project 또는 Company Profile에 저장합니다.
