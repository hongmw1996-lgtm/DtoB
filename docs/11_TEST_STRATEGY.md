# Test Strategy

## Test 종류

### Unit
Geometry 함수

### Fixture
단일 CAD Entity / Block

### Golden
실제 DWG 전체

### Regression
과거 성공한 도면

### Revit Integration
생성된 RVT 검사

## Metric

객체별로 측정:

- Precision
- Recall
- Geometry deviation
- Family match accuracy
- Generation success rate

## Golden Dataset 최소 목표

MVP 종료 전 실제 DWG 10개 이상.
